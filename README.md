# ovenui

A simulator & syntax checker for the Controleo3. Not affiliated in any way.

Features:

- Paste in a program to check it for errors
- Plot expected results of a program
- Easy kiln/oven-specific calibration of the simulation

## Run and check

Requires Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev
npm test
npm run build
```
