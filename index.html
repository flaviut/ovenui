    Syntax quick reference

    Start with Controleo3, then name "My profile". Use one command per line. Commands are case insensitive; comments start with # or //. Strings use double quotes.

    Unit catalog

    ValueUnitExample
    TemperatureDegrees Celsius (°C)maintain 150C for 60 seconds
    Temperature differenceDegrees Celsius (°C)deviation 20C
    Duration / timerSecondswait for 120 seconds
    Heater outputPercent, 0–100%element duty cycle 80/60/0
    Door openingPercent, 0–100%, then secondsdoor percentage 50% over 2 seconds
    Heater biasRelative weightsbias 3/2/1

    Three heater values always mean bottom / top / boost. Numbers must be whole and non-negative, up to 65535.

    1 minute = 60 seconds; 1 hour = 3600 seconds. Unit labels are optional and do not convert values. Write 120 seconds for two minutes; temperatures always use Celsius.
